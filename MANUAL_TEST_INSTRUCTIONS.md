## 🐛 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Ошибка: "Internal Server Error" при сохранении

1. Откройте DevTools (F12) → Console
2. Найдите ошибку с деталями
3. Откройте DevTools → Network
4. Найдите failed запрос (красный)
5. Посмотрите Response
6. Если Response - это HTML вместо JSON, значит API вернул ошибку
7. Проверьте консоль сервера API

### Ошибка: Изображение не сохраняется

1. Проверьте размер изображения (должен быть < 5MB)
2. Проверьте формат (должен быть JPG, PNG, WebP)
3. Проверьте Network в DevTools - возможно запрос слишком большой

### Ошибка: "Unauthorized" или "Forbidden"

1. Проверьте что вы вошли как Admin
2. Проверьте что токен не истек
3. Попробуйте выйти и войти заново
