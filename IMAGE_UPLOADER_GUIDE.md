# 📸 Профессиональный Image Uploader - Руководство

## ✨ Возможности

### 🎯 Основные функции:
1. **Загрузка из галереи** - выбор изображения через file input (браузер запросит разрешение)
2. **Интерактивный редактор** - полноэкранное модальное окно для редактирования
3. **Drag & Drop позиционирование** - перемещайте изображение мышью
4. **Масштабирование** - от 0.5x до 3x с плавным слайдером
5. **Поворот** - от 0° до 360° с точностью до градуса
6. **Автообрезка** - под нужный aspect ratio без потери качества
7. **Предпросмотр** - живой preview с возможностью изменения/удаления
8. **Оптимизация** - конвертация в JPEG с 90% качеством
9. **Base64 хранение** - изображения сохраняются прямо в БД

---

## 📐 Форматы изображений

### 1️⃣ **Square (1:1)** - Сотрудники
- **Размер**: 800x800px
- **Использование**: Фото сотрудников в карточках
- **Особенности**: Круглые аватары, идеально центрируются

### 2️⃣ **Wide (16:9)** - Курсы и Уроки
- **Размер**: 1920x1080px (Full HD)
- **Использование**: Обложки курсов, превью уроков
- **Особенности**: Широкоформатные карточки, как на YouTube

### 3️⃣ **Standard (4:3)** - Опционально
- **Размер**: 1920x1440px
- **Использование**: Расширенные материалы
- **Особенности**: Классический формат для документов

## 🛠️ Технические детали

### Компонент: `ImageUploader.tsx`

**Props**:
```typescript
interface ImageUploaderProps {
  currentImage?: string | null;        // Текущее изображение (base64 или URL)
  onImageSelect: (base64: string) => void; // Callback с новым base64
  aspectRatio?: 'square' | '16:9' | '4:3'; // Формат обрезки
  label?: string;                      // Заголовок секции
  maxSizeMB?: number;                  // Макс. размер файла (по умолчанию 5MB)
}
```

**Пример использования**:
```tsx
<ImageUploader
  currentImage={formData.photoUrl}
  onImageSelect={(base64) => setFormData({ ...formData, photoUrl: base64 })}
  aspectRatio="square"
  label="Фото сотрудника"
  maxSizeMB={5}
/>
```

## 🎯 Алгоритм работы

### 1. Выбор файла
- Пользователь кликает на placeholder
- Браузер открывает file picker (нативный диалог ОС)
- ОС запрашивает разрешение на доступ к галерее
- Пользователь выбирает изображение

### 2. Валидация
- Проверка размера (max 5MB по умолчанию)
- Проверка типа (только image/*)
- Если не прошло - показываем alert

### 3. Загрузка и preview
- FileReader читает файл как DataURL
- Изображение показывается в preview
- Открывается редактор

### 4. Редактирование
- Canvas с реальным размером (hidden)
- Visible image с трансформациями CSS
- Drag: translate(x, y)
- Zoom: scale(value)
- Rotate: rotate(deg)

### 5. Обрезка и сохранение
- Рисуем на canvas с правильными размерами:
  - Square: 800x800
  - 16:9: 1920x1080
  - 4:3: 1920x1440
- Применяем все трансформации
- Конвертируем в JPEG (quality=0.9)
- Получаем base64 string
- Отправляем через callback

### 6. Хранение
- Base64 сохраняется в formData
- При сохранении формы - уходит в БД
- Поле: `photoUrl` (employees) / `image` (courses)

## 📊 Размеры файлов

**До обработки**: любой размер (до 5MB)
**После обработки**:
- Square 800x800: ~50-150 KB
- 16:9 1920x1080: ~100-300 KB
- 4:3 1920x1440: ~150-400 KB

**Оптимизация**:
- JPEG формат (не PNG)
- Quality 90% (баланс качество/размер)
- Разумные выходные разрешения

## ✅ Преимущества решения

1. **Без внешних зависимостей** - чистый React + Canvas API
2. **Профессиональный UX** - как в фоторедакторах
3. **Оптимизация из коробки** - нет огромных файлов в БД
4. **Единообразие** - все изображения одного размера
5. **Не ломается aspect ratio** - карточки всегда выглядят хорошо
6. **Base64 хранение** - не нужен file storage сервер
7. **Темная тема** - поддержка dark mode
8. **Доступность** - работает на всех устройствах
