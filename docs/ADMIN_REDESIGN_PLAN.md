# Admin Panel Redesign - План реализации

## ✅ Что уже готово

1. ✅ JWT Authentication с httpOnly cookies
2. ✅ CORS между Admin и API
3. ✅ Базовый Dashboard
4. ✅ API endpoints для всех ресурсов

## 🎯 Требования к новой версии

### 1. Telegram 2FA
- Генерация 6-значного кода
- Отправка через Telegram Bot
- Валидация кода
- Хранение кодов с TTL

### 2. UI/UX
- Профессиональные иконки (lucide-react)
- Показ/скрытие пароля
- Логотип ОКУРМЕН оранжевый
- Многоязычность (RU/EN/KY)
- Светлая/тёмная тема
- Плавные анимации

### 3. CRUD функционал
- Курсы + уроки внутри курсов
- Сотрудники (добавление/удаление)
- Заявки
- Платежи
- Отзывы
- Выпускники

### 4. Аналитика
- Графики просмотров
- Статистика по курсам
- Активность пользователей

## 📝 Поэтапная реализация

Из-за ограничений времени/токенов, реализация будет в несколько этапов:

### Этап 1 (текущий)
- ✅ Установка библиотек
- ⏳ 2FA Telegram endpoints
- ⏳ Улучшенная страница signin
- ⏳ Contexts (язык, тема)
- ⏳ Новый layout с логотипом

### Этап 2 (следующая сессия)
- Dashboard с графиками
- CRUD для курсов
- CRUD для сотрудников

### Этап 3 (следующая сессия)
- Остальные CRUD страницы
- Полная аналитика
- Финальное тестирование
