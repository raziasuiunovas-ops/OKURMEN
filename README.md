# ОКУРМЕН IT — Landing Page

Современный Landing Page для IT-образовательного проекта ОКУРМЕН с поддержкой 3 языков.

## 🚀 Технологии

- **Next.js 15** — React-фреймворк с App Router
- **TypeScript** — строгая типизация
- **Tailwind CSS** — utility-first CSS
- **next-intl** — интернационализация (ky/ru/en)
- **Framer Motion** — анимации (planned)

## 📁 Структура проекта

```
OKURMEN/
├── apps/
│   └── web/               # Next.js Landing Page
│       ├── app/
│       │   └── [locale]/  # Локализованные маршруты
│       ├── components/    # React компоненты
│       │   └── sections/  # Секции Landing Page
│       └── i18n/          # Конфигурация локализации
│
├── packages/
│   ├── ui/                # Переиспользуемые UI компоненты
│   └── i18n/
│       └── messages/      # Переводы (ky.json, ru.json, en.json)
│
└── docs/                  # Документация проекта
```

## 🌍 Языки

Проект поддерживает 3 языка:

- 🇰🇬 **Кыргызский** (kg) — кыргызча
- 🇷🇺 **Русский** (ru) — по умолчанию
- 🇬🇧 **English** (en)

## 📄 Секции Landing Page

1. **Hero Section** — главный экран с анимациями
2. **About OKURMEN** — информация о проекте, основателях, статистика
3. **Why OKURMEN** — преимущества (6 карточек)
4. **Hybrid Learning** — визуальная схема процесса обучения
5. **Courses** — универсальные карточки курсов (TBD)
6. **Additional Activities** — дополнительные направления
7. **Team** — команда (основатели, преподаватели)
8. **Mentors** — роль менторов (до 50 учеников/ментор)
9. **Students & Alumni** — достижения выпускников (Apple, мэрия, Kulikovsky, Казахстан)
10. **Grant** — грант 10 000 сом
11. **Reviews** — отзывы студентов и родителей (структура готова)
12. **Laptops** — покупка ноутбуков
13. **Contacts** — контакты и форма заявки
14. **Footer** — навигация, статистика, информация

## 📋 Требования

Перед запуском установите зависимости:

```bash
cd apps/web
npm install
```

## 🔧 Запуск проекта

```bash
# Development
cd apps/web
npm run dev

# Production build
npm run build
npm start
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.
