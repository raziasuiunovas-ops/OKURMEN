# ✅ 2FA теперь работает правильно!

## Что было исправлено

**Проблема:** Можно было войти в админ-панель БЕЗ кода из Telegram.

**Решение:** Теперь вход ТОЛЬКО через Telegram 2FA. Обойти невозможно.

## Как войти в админ-панель

### Шаг 1: Откройте страницу входа
```
http://localhost:3001/auth/signin
```

### Шаг 2: Введите email и пароль
```
Email: admin@okurmen.kg
Password: Admin123!LocalDev
```

### Шаг 3: Нажмите "Получить код"
- Код будет отправлен в Telegram
- Откройте Telegram и найдите сообщение от бота

### Шаг 4: Введите 6-значный код
- Введите код из Telegram
- Нажмите "Войти"
- Вы будете перенаправлены на `/admin`

## Проверка что 2FA работает

### Тест 1: Попытка обойти 2FA (должна провалиться)
```bash
curl -X POST http://localhost:3002/api/auth/signin \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@okurmen.kg","password":"Admin123!LocalDev"}'
```

**Ожидаемый результат:** ❌ Ошибка "Требуется двухфакторная аутентификация"

### Тест 2: Правильный вход через 2FA
1. Откройте `http://localhost:3001/diagnostic`
2. Используйте "Manual 2FA Test"
3. Введите email/password
4. Нажмите "1. Request 2FA Code"
5. Проверьте Telegram - должен прийти код
6. Введите код
7. Нажмите "2. Verify Code"

**Ожидаемый результат:** ✅ Получен токен, можно войти

## Если что-то не работает

### Код не приходит в Telegram
1. Проверьте файл `.env`:
   ```bash
   TELEGRAM_BOT_TOKEN="8638005611:AAGfmLC7UBqA4mKHh26f-0MYVDiwM2-gOqk"
   TELEGRAM_CHAT_ID="1376366540"
   ```
2. Перезапустите API:
   ```bash
   cd apps/api
   pnpm dev
   ```

### "Неверный код"
- Код действителен 30 минут
- Запросите новый код
- Используйте самый последний код из Telegram

### После ввода кода не переходит на /admin
1. Откройте консоль браузера (F12)
2. Проверьте:
   ```javascript
   localStorage.getItem('auth-token')
   ```
3. Если токена нет - проблема на backend, проверьте логи API
